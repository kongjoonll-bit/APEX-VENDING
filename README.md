## 🚀 설치 방법

### 1) 로컬 실행

```bash
pip install -r requirements.txt
```

`.env` 파일 생성:

```env
DISCORD_TOKEN=your_discord_bot_token
SECRET_KEY=any_long_random_string
# (선택) 재배포해도 웹훅 키를 고정하고 싶을 때
DEPOSIT_WEBHOOK_KEY=your_fixed_webhook_key
```

```bash
python main.py
```

- 웹 대시보드: `http://localhost:5000`
- 디스코드에서 `/자판기설정` 입력 → 현재 채널에 자판기 설치

### 2) Render 배포

1. GitHub에 이 폴더 업로드 (`.env`, `data/`, `__pycache__/` 제외)
2. Render → **New > Web Service** → 저장소 연결
3. 설정
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `gunicorn main:app --bind 0.0.0.0:$PORT --workers 1 --threads 4 --timeout 120`
   - **Environment Variables**: `DISCORD_TOKEN`, `SECRET_KEY` (+ 선택: `DEPOSIT_WEBHOOK_KEY`)
4. Deploy
5. 대시보드 로그인 후 **설정** 탭에서 **관리자 비밀번호**를 반드시 변경하세요.

> ⚠️ Render 무료 플랜은 디스크가 영구적이지 않아 재시작 시 `data/vending.db`가 초기화될 수 있습니다.
> 대시보드 설정에서 **대시보드 URL**을 저장해 두면 5분마다 자동 핑으로 슬립을 방지합니다.

구매 완료 DM과 후기 게시물은 **Pillow로 생성한 카드 이미지**로 전송됩니다.

```

구매 완료
구매가 정상적으로 완료되었습니다
┌ 결제 금액                      랜덤로벅쿠키 ┐
│ 1,000원                    로벅스 쿠키 · 1개 │
└─────────────────────────────────────────┘
구매자   송산        카테고리   로벅스 쿠키
상품     랜덤로벅쿠키   갯수      1개
할인     없음
구매 ID ef0cc3d4b3a4d3494142        2026. 11. 09. 16:27
```

- 카드 생성 모듈: `card_render.py` (Pretendard 폰트를 `data/fonts` 에 1회 자동 다운로드, 오프라인이면 시스템 폰트로 대체)
- 구매 완료 시: 카드 이미지 + (파일 재고라면) **파일 첨부** / (텍스트 키라면) 키 코드블록을 같은 DM으로 전송

- 대시보드 **설정 → 구매완료 / 후기 카드 이미지** 에서 끄고 켤 수 있습니다 (`card_image_enabled`)

## 🍪 로블록스 쿠키 자동 유효성 검사

TXT 재고 파일에 담긴 **로블록스 쿠키(.ROBLOSECURITY)** 를 **기본 3분마다 자동 검사**합니다.

### 동작 규칙
1. 파일 내용에서 **`_|WARNING` 부터 파일 끝까지**를 쿠키로 사용합니다.
   (앞에 아이디/비밀번호 같은 계정 정보가 붙어 있어도 무시)
2. 쿠키가 아닌 일반 TXT(강의자료 등)는 검사 대상에서 자동 제외됩니다 (`쿠키 없음`).
3. 검사 결과
   | 결과 | 처리 |
   |---|---|
   | ✅ 유효 (HTTP 200) | 계정명·ID 저장, 정상 판매 |
   | ⛔ 무효 (HTTP 401/403) | **자동으로 판매 중지** + 관리자 채널 알림 + 자판기 재고 갱신 |
   | ⚠️ 판단불가 (네트워크/서버 오류) | 기존 상태 유지 (잘못 무효 처리하지 않음) |
4. 무효 쿠키는 `get_available_key` 단계에서 제외되므로 **구매자에게 절대 지급되지 않습니다.**
5. 재고가 많으면 검사 이력이 오래된 것부터 순환 검사합니다(1회 최대 60개 · 요청 간 0.7초 간격).

### 자판기 패널 표시
패널 하단에 **마지막 쿠키 검사 시각과 재고 현황**이 자동 표시됩니다. (파일 재고가 있을 때만)

```
# APEX VENDING
--------------------------------
원하시는 메뉴를 선택해주세요.
[카테고리 ▼]   [🛒 구매] [💳 충전] [ℹ️ 정보] [✉️ 문의]
--------------------------------
상품 3종 · 재고 12개 · 판매중 2종
쿠키 유효성 검사 18초 전
유효 9 · 무효 3 · 판매가능 9
APEX VENDING · 24/7 AUTO DISPENSER
```

> 버튼 4개에만 아이콘을 사용하고, 그 외 텍스트/임베드/안내문에는 이모지를 쓰지 않습니다.

- 검사가 끝나면 시각이 갱신되고, **1분마다 자동으로 다시 그려져** "N초 전 / N분 전"이 계속 최신으로 유지됩니다.
- 아직 한 번도 검사 전이면 `쿠키 유효성 검사 대기 중` 으로 표시됩니다.

### 🚫 만료 파일은 판매되지 않습니다 (핵심)
아래 조건을 **모두** 만족하는 재고만 실제로 판매됩니다.

| 조건 | 설명 |
|---|---|
| `invalid = 0` | 무효 판정을 받지 않은 쿠키 |
| 검사 시각 최신 | 마지막 검사가 **판매 허용 최대 검사 경과(기본 10분)** 이내 |

→ 따라서 **① 검사 전 재고 ② 검사가 오래된 재고 ③ 무효(만료) 쿠키**는 모두 자동으로 판매 보류됩니다.
- 자판기·대시보드의 **재고 수량도 '실제 판매 가능한 수량'** 으로 계산됩니다.
- 구매 시도 시 살 수 있는 재고가 없으면 `"만료된 쿠키이거나 유효성 검사 중"` 안내가 출력됩니다.
- 파일을 등록하면 **즉시 1회 검사**가 실행되어 곧바로 판매 가능 상태가 됩니다.
- 검사가 네트워크 오류로 실패하면 **검사 시각을 갱신하지 않아**, 일정 시간 후 자동으로 판매가 보류됩니다. (안전 우선)
- 대시보드 재고 목록에서 `✅ 유효 / ⏸ 판매보류(검사 갱신 필요) / ⛔ 무효 / ⏳ 미검사` 로 구분 표시됩니다.

### 설정 (대시보드 → 설정)
- **로블록스 쿠키 자동 검사**: 사용 / 사용 안함 (`cookie_check_enabled`)
- **쿠키 검사 주기(분)**: 기본 `3` (`cookie_check_minutes`)
- **판매 허용 최대 검사 경과(분)**: 기본 `10` (`cookie_max_age_minutes`) — 이 시간이 지나면 판매 보류

> 자동 검사를 꺼도 **파일 등록 시 1회 검사**는 수행됩니다.
> 검사 이력이 전혀 없는 재고는 판매되지 않으므로, 기존에 올려둔 파일은 `/쿠키검사` 로 한 번 검사해 주세요.

### 수동 검사
- 디스코드: `/쿠키검사` → 즉시 전체 검사 후 요약(유효/무효/판단불가/새로 제외)
- 대시보드: **재고 관리** 탭 → `🔄 쿠키 재검사` (전체) / 각 파일 행의 `검사` (1건)
- 재고 목록에 `✅ 유효 / ⛔ 무효 / ⏳ 미검사` 배지와 **계정명·검사시각·사유**가 표시됩니다

> 검사 API: `GET https://users.roblox.com/v1/users/authenticated` (쿠키 헤더 `.ROBLOSECURITY=...`)

## 🎛 버튼 아이콘 (커스텀 이미지)

버튼 아이콘은 유니코드 이모지가 아니라 **직접 생성한 PNG 아이콘**입니다.

```
assets/icons/
├─ cart.png     구매
├─ box.png      제품
├─ card.png     충전
├─ info.png     정보
├─ mail.png     문의
└─ refund.png   환불
```

- 봇이 시작되면 이 PNG들을 **Discord 애플리케이션 이모지**(`apex_cart` 등)로 자동 업로드하고,
  버튼에는 커스텀 이모지로 표시합니다. (서버에 따로 이모지를 올릴 필요 없음)
- 이미 업로드된 이모지는 재사용하며 ID를 DB에 저장합니다.
- 업로드 권한/네트워크 문제로 실패하면 **아이콘 없이 텍스트만** 표시됩니다(기능 동일).
- 아이콘을 바꾸고 싶다면 `assets/icons/` 의 PNG를 교체하고, Discord 개발자 포털의
  애플리케이션 이모지를 삭제한 뒤 봇을 재시작하면 다시 업로드됩니다.
- 그 외 텍스트/임베드/안내문에는 이모지를 사용하지 않습니다.

## 📄 파일(.txt) 상품 등록 & 배송

키 코드 대신 **파일 자체를 재고로 등록**해서 판매할 수 있습니다. (파일 1개 = 재고 1개)

### 디스코드에서 등록
```
/파일추가 product_id:1 file:강의자료.txt
```
- `file2`, `file3` 로 한 번에 최대 3개까지 등록할 수 있습니다.
- 등록된 파일은 구매 시 **DM 첨부파일**로 전송되고, 구매 로그/주문 내역에는 파일명과 크기가 표시됩니다.
- 텍스트 키는 기존처럼 `/키추가` 로 등록합니다.

### 대시보드에서 등록
1. **재고 관리** 탭 → **📄 파일 추가**
2. 상품 선택 → 파일 선택(다중 가능) → **업로드**
3. 재고 목록에서 타입 `📄 파일` / 다운로드 링크 / 삭제 버튼으로 관리

> · 파일 1개당 최대 **8MB** (Discord DM 첨부 한도 고려)
> · .txt 권장 (.md/.csv/.json/.zip/.pdf 등도 가능)
> · 파일 원본은 SQLite `keys.file_data`(BLOB)에 저장됩니다 → DB 백업 시 함께 보관됩니다.

## 🔐 자동 입금(토스 + Tasker) 요약

1. 유저가 자판기에서 `💳 충전` → **충전 신청**(입금자명 + 금액) 등록
2. 대시보드 **설정 → 입금 자동감지 웹훅 URL**을 폰 Tasker에 등록
3. 실제 입금 알림이 오면 금액 + 입금자명이 일치할 때 **자동 충전**
4. 3분 내 자동 충전이 안 되면 유저에게 DM 리마인더 → 스크린샷 수동 승인 가능

자세한 Tasker 설정은 대시보드 **설정** 탭의 안내를 참고하세요.
